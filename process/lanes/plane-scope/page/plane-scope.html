What the plane is, in one paragraph

Civicsmith is built as about two hundred parts, called modules, in a fixed order; each part may only use parts before it. The plane is the part near the end that puts all the others together into the one program a team actually runs on the hosting service. Its own code is small: it starts every other part on one store, hands requests to the front door, and wakes the scheduler. It decides nothing itself.

Why it has become a problem

9files of its own
105test entries given to it
171other parts it says it uses
33–44 minto run its tests, against a 45 min limit

When the parts were put in order, any test that starts the whole program was given to the plane, because only the last part may use everything. Many of those tests were written to prove other parts' promises. So the plane carries other parts' proof, its test run is close to the time limit, and a change to any of those other parts is not proven when that part's own work runs.
