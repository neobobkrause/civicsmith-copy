# agent-worker-routes: requirements

Next number: 120

## Public

### Purpose

The agent worker's member-facing paths, split from `agent-worker` (P6): `POST /ask`, `POST /draft` (writing help, translation, action and reading tasks), `POST /transcribe` and `POST /signin`, with the op lists (`ops.mjs`), the test-instance label and the remote-session dispatch they share. `agent-worker`'s Worker shell calls each path's handler; each composes its answer through `agent-model` under the account that serves the member's act, keeps nothing between calls, and relays a member's own Claude sign-in to that member's runner without holding it.

### Provides

**`POST /ask`** (Q1-4; ladders §9.4 L1; K1450, K1474, K1479, K1502)

It writes no run row and no observation, and reports each model call's `usage` to the plane (`ai-runs` R48's `countAskUsage`). Progress is streamed as each step begins (interpreting, each read with its op, composing, checking), carrying no text the checks have not passed.
