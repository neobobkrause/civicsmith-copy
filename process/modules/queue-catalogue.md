Next number: 97

## Public

### Purpose

The queue's catalogue, split from `queue` (P6): `queuestate.mjs`, pure, which answers each kind's class and sentence, the condition kinds, an item id's class, and the personal half's mute grammar (`suppressedBy`, `mutedAsItem`, the muted kinds' serialisation). `queue` mints, homes and publishes items by it; nothing here reads the record or writes.

- **R2** [met] `catalogueIdOf(kind)` answers `N-1` for export-performed and null for every other kind.
- **R3** [met] `itemClassOf(id)` answers `FINDING` or `CONDITION` for an id `FINDING::<rest>` or `CONDITION::<rest>` (trimmed) with a non-blank rest, else null.
- **R4** [met] `suppressedBy(item, mutes)` (`mutes` a map of case id to a set of kinds) answers the first of the item's ancestors whose set holds the item's kind, else null; there is no wildcard, so a kind not named when the mute was made is not suppressed. `mutedAsItem(item, set)` is true only for a CONDITION or FINDING whose id is in the set. `serializeMutedKinds` answers the sorted, de-duplicated, comma-joined set; `parseMutedKinds` inverts it.
