# jurisdiction-profiles: requirements

Next number: 99

## Public

### Purpose

The jurisdiction profiles themselves, as data: the first profile (the city and county whose facts the product carries, `profiles/oakland-alameda.mjs`), each fact with the measurement it rests on, and the test profile of a fictional place (`profiles/test-port-ellery.mjs`). Only these files name a place; `jurisdictions` holds, validates and combines them.

### Provides

**combine(list) → `{ok: true, view, conflicts}` or `{ok: false, errors}`.** `list` is the active profiles, in order: each is a held profile's `id` or a profile object. Which profiles are active is an instance setting held by the record. This module takes the list and does not store it.
- **R95** [met] (T51 fix round 3, C64; DEC-402; ENTITIES #18's finding (a); K4407; amends R7, R76) **The federal records law.** The first profile's `records_laws` also holds the federal Freedom of Information Act (`level: federal`, citation 5 U.S.C. § 552), with its stages (R76) and requesters, each `researched` with its basis, so a member naming a federal office from a request (`entities` R63) can name it as the office's law. Test: `governingLawsOf` and the profile check accept it; control: an unlisted law is still refused.

### Suggestions

- Layout: `jurisdictions/index.mjs` for the services, and one data file per profile under `jurisdictions/profiles/`. Only those data files, and this module's tests of them, name a place.
- **T48 (T48-2): how the job gets the first profile's pointers (R92).** The job's session reads each body's own page with its web tool and records the address and the date read, the M-note form R56 and R85 use. A host the session's network refuses is named in the job's record, and that pointer stays absent. Nothing comes from memory, from the mockup or from a secondary aggregator where the body publishes its own page. If no primary page can be reached at all, the job stops and says so; that is a hard reason for R92 alone, and R89–R91 still merge. The `legalaid` official list is likely the State Bar's Legal Services Trust Fund grantees serving the county; the job names the list it used at START.
- Known bases for the first profile: M-119, M-132 and M-157 (identifiers and systems); M-18 and M-24 (minutes, staff report, ordinance or resolution); M-121 (directory: it has no local vocabulary in code); and dated entries in `MEASUREMENTS.md` (the calendar and handlers, 2026-07-30; the agenda, FW-15).
